Olá!

O meu nome é Tomás Pinto e este é o meu projeto de PAP: um software de djing simples e intuitivo com o objetivo de tornar a prática do djing mais acessível a djs iniciantes e/ou a utilizadores que procurem alternativas básicas ás complexas existentes no mercado.

Admito que cometi alguns erros neste projeto, mas o principal foi ter perdido o histórico de commits do projet ao acidentalmente ter feito --force ao guardar alterações recentes (o que sobrepôs as antigas). No entanto, na altura do outono e do inverno (entre outubro a janeiro) apontava num caderno as alterações que ia fazendo e, voltando atrás, encontrei registos de mudanças que ia fazendo.

Depois escrevi-as com as devidas datas no bloco de notas e enviei para a ia para me enviar commits construidos com base nelas.
